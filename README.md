# مصاريف البيت

تطبيق ويب بسيط لتتبع مصاريف البيت اليومية، يعمل بالكامل في المتصفح ويحفظ البيانات محليًا على جهازك (localStorage) دون الحاجة إلى خادم أو اتصال بالإنترنت.

## المزايا
- إضافة مصروف جديد (المبلغ، التصنيف، الوصف، التاريخ)
- تصنيفات جاهزة: طعام، مواصلات، فواتير، صحة، تسوق، ترفيه، تعليم، أخرى
- ملخص سريع: إجمالي الشهر الحالي، الإجمالي الكلي، وعدد العمليات
- توزيع المصاريف حسب التصنيف لهذا الشهر
- تصفية السجل حسب الشهر أو التصنيف
- حذف أي عملية بضغطة واحدة

## التشغيل
لا يحتاج التطبيق إلى تثبيت أي شيء. فقط افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح.

## هيكل الملفات
- `index.html` — الصفحة الرئيسية
- `assets/style.css` — التنسيق (يدعم الاتجاه من اليمين لليسار)
- `assets/app.js` — منطق التطبيق والتخزين المحلي
