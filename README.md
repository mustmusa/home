# مصاريف البيت

تطبيق ويب لإدارة مشتريات ومصاريف بيتين ومخزن مشترك بينهما، بأربعة مستخدمين بصلاحيات مختلفة:

- **زوجة 1 / زوجة 2**: تكتب رسالة نصية حرة بالاحتياجات، والذكاء الاصطناعي يفسّرها ويحوّلها لقائمة عناصر منفصلة.
- **مسؤول المخزن**: يضيف عناصر اشتُريت بعرض للتخزين، ويسحب منها لأحد البيتين عند الحاجة.
- **الأدمن (أنت)**: كل الصلاحيات — يشتري الاحتياجات، يصوّر الفاتورة (الذكاء الاصطناعي يقرأ عناصرها ويقترح مطابقتها بالطلبات)، ويطّلع على تقارير شهرية/سنوية لكل بيت والمخزن وكل عنصر.

---

## 1) الحساب الذي ستحتاجه

| الخدمة | لماذا | التكلفة |
|---|---|---|
| [Supabase](https://supabase.com) | قاعدة البيانات وتخزين صور الفواتير | مجاني (Free tier) |
| [Vercel](https://vercel.com) | استضافة التطبيق | مجاني (Hobby) |
| [console.anthropic.com](https://console.anthropic.com) | تفسير رسائل الطلبات وقراءة الفواتير بالذكاء الاصطناعي | مدفوع حسب الاستخدام (بسيط جدًا لحجم بيتين) |

سجّل دخول Vercel وSupabase بـ **"Sign in with GitHub"** (نفس حساب GitHub الذي عندك) — ما يحتاج إيميل أو باسورد جديد.

---

## 2) إعداد Supabase (قاعدة البيانات)

1. ادخل [supabase.com](https://supabase.com) → **New project**. اختر اسمًا وكلمة مرور لقاعدة البيانات (احفظها، لن تحتاجها لاحقًا لكن احتياطًا) والمنطقة الأقرب لك.
2. بعد إنشاء المشروع، افتح من القائمة الجانبية **SQL Editor** → **New query**.
3. افتح ملف [`supabase/schema.sql`](./supabase/schema.sql) من هذا المستودع، انسخ محتواه كاملًا، الصقه في المحرر، واضغط **Run**.
4. من القائمة الجانبية افتح **Storage** → **New bucket** → اسمه بالضبط `invoices`، واختر **Private**.
5. من القائمة الجانبية افتح **Settings → API**. ستحتاج قيمتين بالخطوة القادمة:
   - **Project URL**
   - **service_role key** (سرّي جدًا — لا تشاركه مع أحد ولا تضعه في كود يُنشر للعامة)

---

## 3) إعداد مفتاح Anthropic

1. ادخل [console.anthropic.com](https://console.anthropic.com) وأنشئ حسابًا.
2. من **Billing** أضف وسيلة دفع (بطاقة ائتمان) واشحن رصيدًا بسيطًا (5-10 دولار كافية للبداية).
3. من **API Keys** أنشئ مفتاحًا جديدًا وانسخه (يبدأ بـ `sk-ant-...`) — يظهر مرة واحدة فقط.

---

## 4) النشر على Vercel

1. ادخل [vercel.com](https://vercel.com) → سجّل دخول بـ GitHub.
2. **Add New → Project** → اختر مستودع `mustmusa/home` (هذا المستودع) → **Import**.
3. Vercel يكتشف أنه مشروع Next.js تلقائيًا. قبل الضغط على Deploy، افتح **Environment Variables** وأضف:

   | الاسم | القيمة |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL من خطوة Supabase |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key من خطوة Supabase |
   | `SUPABASE_INVOICES_BUCKET` | `invoices` |
   | `ANTHROPIC_API_KEY` | مفتاح Anthropic |
   | `SESSION_SECRET` | نص عشوائي طويل (مثلًا 40 حرفًا عشوائيًا — أي نص تكتبه بنفسك كافٍ) |

4. اضغط **Deploy** وانتظر دقيقة أو اثنتين.
5. بعد اكتمال النشر، افتح الرابط الذي يعطيك إياه Vercel.

---

## 5) أول استخدام

1. افتح رابط التطبيق، وستُحوَّل تلقائيًا لصفحة الدخول. اضغط **"أنشئ حساب الأدمن من هنا"** (يظهر فقط أول مرة).
2. أدخل اسمك ورقم جوالك ورمزًا سريًا (4 أرقام أو أكثر) — هذا حسابك أنت بكل الصلاحيات.
3. بعد الدخول، من تبويب **"المستخدمون"** أضف باقي الحسابات الثلاثة:
   - زوجة 1 (اربطها ببيت 1)
   - زوجة 2 (اربطها ببيت 2)
   - مسؤول المخزن
4. أعطِ كل شخص رقم جواله والرمز السري الذي اخترته له، ويدخل من نفس رابط التطبيق.

يمكنك أيضًا تعديل أسماء "بيت 1" و"بيت 2" لأسماء حقيقية من نفس التبويب.

---

## 6) كيف تعمل الميزات الرئيسية

- **طلب الزوجة**: تكتب أي نص حر ("محتاجين رز وزيت وكيلوين دجاج") وتضغط إرسال — الذكاء الاصطناعي يفصلها لعناصر منفصلة تلقائيًا.
- **فاتورة جديدة (تبويب الأدمن)**: صوّر الفاتورة من الجوال مباشرة، الذكاء الاصطناعي يقرأ كل سطر ويقترح مطابقته بأحد الطلبات المعلّقة (أو يفترضه للمخزون إن لم يطابق شيئًا) — راجع وعدّل قبل الحفظ.
- **المخزون**: مسؤول المخزن أو الأدمن يضيف عناصر اشتُريت بعرض، ويسحب منها لأي بيت عند الحاجة — يُحتسب تلقائيًا كمصروف على ذلك البيت.
- **التقارير**: مصروف كل بيت شهريًا، قيمة المخزون الحالي، وتكلفة كل عنصر شهريًا/سنويًا لتتبع تغيّر الأسعار مع الوقت.

## التطوير محليًا (اختياري)

```bash
npm install
cp .env.example .env.local   # ثم عبّي القيم الحقيقية
npm run dev
```
